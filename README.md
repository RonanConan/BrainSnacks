# Brain Snacks

Short, cosy puzzles with hints and answers: sudoku, mini crosswords, maths, a random quiz, word scramble, riddles, memory match and picture logic grids.

It's a static site with no build step, so any static host can serve it as is. Progress is saved in the visitor's own browser.

Play locally:

```bash
npm start
```

Then open http://localhost:5173.

Run the puzzle and content checks:

```bash
npm test
```
